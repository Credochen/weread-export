微信读书导出器

把你有阅读权益的书导出成本地 EPUB。全程本机运行，Cookie 只留在内存里。

1连接配置

在浏览器打开要导出的书，把地址栏整条复制过来即可。
两种格式都认：插件导出的 JSON 数组，或 wr_vid=...; wr_skey=... 形式的请求头。其他站点的条目会自动忽略。

Cookie 怎么拿？
  1. 浏览器打开 weread.qq.com 并登录。
  2. 按 F12 打开开发者工具，切到 Network，筛选 Fetch/XHR。
  3. 随便点一个请求，在 Request Headers 里找到 Cookie: 整行。
  4. 至少要有 wr_vid、wr_skey、wr_rt 三个。

2选择范围

逗号分隔；1-20 表示第 1 到 20 章，60- 表示第 60 章到末尾。
